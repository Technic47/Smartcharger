## 0. Подготовка (до первого включения)

- [ ] Плата отмыта от флюса (спирт/растворитель, зубная щётка), высохла
- [ ] Желательно: покрыта лаком (Plastik 70 или аналог)
- [ ] Визуальный осмотр под лупой: нет перемычек между дорожками CC-цепи (D44–10к–RC–560R–диод–FB)
- [ ] Прозвонка: диод D3 в цепи CC (анод к RC-узлу, катод к FB) — ~0,5–0,7 В в прямом направлении
- [ ] Прозвонка: нет КЗ узла FB на GND и на +5В
- [ ] ACS712 подключён: VCC 5В (проверить 4,95–5,05 В), GND общий, VIOUT → A10
- [ ] Нагрузка готова: 3 лампы 12 В 20 Вт (переключаемые) + клеммы для резисторов/болта

## 3. Сырая проверка CC-цепи (команда `cc N`)

Цепь: D44 → 10к → (1 мкФ ‖ 100к) → 560R → диод → FB. Больше duty = больше инжекции = **ниже** выход.

| Шаг | Команда / действие | Ожидается | Факт | Ок? |
|---|---|---|---|---|
| 3.1 | Нагрузка 1 лампа, `on`, `i 8` | mode=CV, ток лампы полный | | |
| 3.2 | `cc 0` | Без изменений (нет инжекции) | | |
| 3.3 | `cc 200` | Выходное напряжение заметно упало / ток ограничен | | |
| 3.4 | `cc 500` | Ещё ниже; PI заморожен 3 с (`raw CC duty=500 (PI frozen 3 s)`) | | |
| 3.5 | `cc 1023` | Минимум напряжения, который даёт цепь | | |
| 3.6 | Подождать 3–4 с или `i 8` | PI снова в управлении (duty живёт своей жизнью) | | |

**Если `cc 1023` почти не меняет выход — проверять: пайку 560R и диода, полярность диода, нет ли 470к вместо 10к.**

**Критерии pass:**
- Ошибка тока ≤ ±0,1 А в середине шкалы (1–5 А)

## Настройка PI (если раздел 4/5 не проходит)

Симптом → что крутить в шапке .ino (KP / KI / пороги):

| Симптом | Вероятная причина | Действие |
|---|---|---|
| Ток медленно ползёт к уставке 5+ с | KI мал | KI ×2 |
| Ток доходит скачком, перелёт, качели | KP велик | KP ×0,5 |
| Возрастающие осцилляции вокруг уставки | KI велик | KI ×0,5, KP ×0,8 |
| Низ шкалы точно, верх занижен | Не PI, а питание/датчик | Проверить 5В, калибровку `cal i`, достаточность duty 1023 |
| mode CC↔CV дёргается на границе | Пороги latch | CC_PI_DUTY_OFF ↑ (например 25) |
| После снятия CC напряжение долго восстанавливается | Не CC-контур, а CV | Лог `log 1`, смотреть `trim` — отдельная история |

После каждой смены коэффициентов: пересобрать, прошить, повторить разделы 4–5 (полный цикл ~5 минут).
